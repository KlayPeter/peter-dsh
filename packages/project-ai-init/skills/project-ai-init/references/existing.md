# 已有项目

读取已发现的 manifest、锁文件、现有指令、README、功能索引和 CI。多包项目分别核对每个子目录的工具链，不从后端 Bun 推断前端也必须换成 Bun。扫描只给出可验证线索，未自动理解业务架构。

保留项目的业务文档位置、命名和命令。没有测试脚本就说明未知；不能因为写了测试要求便生成一个假的 npm test。初始化时不执行数据库迁移、部署、setup 等现有脚本。

新项目默认把具体命令、项目提醒和必要偏好直接写入 AGENTS.md 的受管理区域。已有 AGENTS.md / CLAUDE.md 内容保持原样；仅 expanded 布局引用 .agent-context 文件；已有规则够用时不为了初始化再复制一套。先读取原有规则，语义有冲突时不直接应用偏好。

对已有大文件的精简是另一种明确修改：可以参考上游 agent-md-refactor，但不能在“补齐配置”的任务里顺手重写整份 AGENTS.md。项目已有 FEATURE.md 体系时优先沿用，缺失时给出渐进建立的方法，不自动编造业务能力卡。
