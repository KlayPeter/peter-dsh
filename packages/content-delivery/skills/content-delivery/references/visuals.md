# 图示选择与交付

先写下该图要回答的读者问题，再选择表达。没有关系、分支或结构要解释时，正文、列表或表格通常足够。

| 信息 | 优先表达 |
| --- | --- |
| 条件、决策、重试 | 流程图 |
| 多方按时间交互 | 时序图 |
| 生命周期和迁移条件 | 状态图 |
| 模块边界和依赖 | 分层架构图 |
| 数据实体及基数 | ER 图 |
| 同口径数据比较或趋势 | 基于已提供数据的图表工具，保存数据及源文件 |
| 概念直觉或场景 | 可选生成式插画 |

当前导出器支持 mermaid 代码块及相对路径 PNG/JPEG/WebP 图片。Mermaid 只写普通图语法，不带 init 指令或 YAML 配置。导出时保存 mmd 源和 PNG，HTML 内嵌 PNG；PDF／Word 使用同一图资源。

每张图提供上下文、标题或图注，解释读图要点。复杂图按问题拆分，检查标签、箭头、图例、对比度和最终页面上的字大小。

图的数据和关系必须与正文一致。结构化图画得出来不等于语义正确；插画的文字也需检查。不要用生成式插画代替要求精确的数据图或接口图。

需要语法细节时按 upstream.md 读取 mermaid-diagrams 的对应参考文件；需要判断图是否值得画时读取 utility-mermaid-diagrams。文章插画是独立可选后端，导出器不会偷偷调用收费图像服务。
